# Screenshots Directory

Please place your three screenshot images in this directory (`public/screenshots/`):

1. **`desktop-ui.png`** (or `.jpg`) — Desktop Vaults & Hero UI overview.
2. **`mobile-ui.png`** (or `.jpg`) — Mobile responsive dApp view.
3. **`analytics-dashboard.png`** (or `.jpg`) — Telemetry, Health & Analytics / Reversal dashboard.

Once placed here, these will automatically be accessible to the frontend and documentation at `/screenshots/<filename>`.
